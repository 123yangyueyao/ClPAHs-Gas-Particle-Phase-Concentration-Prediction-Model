This folder contains four Jupyter notebooks for predicting chlorinated PAHs (ClPAHs) in ambient air, split into gas-phase and particle-phase.

1. ClPAHs_Gas_Phase_Prediction.ipynb — gas-phase prediction (two-stage XGBoost).
2. SHAP_ClPAHs_Gas.ipynb — SHAP interpretation of the gas-phase model.
3. ClPAHs_Particle_Phase_Prediction.ipynb — particle-phase prediction.
4. SHAP_ClPAHs_Particle.ipynb — SHAP interpretation of the particle-phase model.
